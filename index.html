The 60–30–10 Rule

A practical starting point for balanced color distribution.

60%
30%
10%

Balance creates hierarchy.

60% — Dominant: Main background and large visual areas.

30% — Secondary: Cards, sections and supporting surfaces.

10% — Accent: Primary buttons, links and important highlights.

Use this as a guideline, not a strict requirement. Text, imagery and layout also affect the perceived ratio.

Color Design Principles

Practical principles for making simple websites feel more polished.

◈

1. Define color roles

Assign separate roles to backgrounds, surfaces, text, borders and actions. Consistent roles make large websites easier to maintain.

◉

2. Use psychology carefully

Blue can communicate stability, green can suggest nature and muted gold can support luxury branding. Context and audience matter more than stereotypes.

✦

3. Limit accent colors

One dominant accent is often enough. Reserve it for meaningful actions instead of coloring every element.

▤

4. Check contrast

Normal text generally needs a WCAG contrast ratio of at least 4.5:1. Large text generally needs 3:1. Test real text and backgrounds.

◐

5. Design for dark mode

Don't simply invert every color. Use layered surfaces, readable muted text and restrained accents. Test contrast again.

◎

6. Keep the whole UI consistent

Apply the same design tokens to buttons, links, forms, cards, hover states and focus indicators. Color alone should never communicate status.

A professional color workflow

01. Identify the brand and audience.   02. Select a category and mood.   03. Choose a palette.   04. Assign semantic color roles.   05. Preview actual components.   06. Check contrast and keyboard focus.   07. Test with users and refine.
